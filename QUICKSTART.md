# 🚀 LokuResume AI - Quick Start Guide

## ⚡ Start Development in 3 Steps

### 1️⃣ Start Backend (Terminal 1)

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

✅ Backend running at: **http://localhost:8000**  
📚 API Docs: **http://localhost:8000/docs**

---

### 2️⃣ Start Frontend (Terminal 2)

```bash
cd frontend
npm run dev
```

✅ Frontend running at: **http://localhost:5173**

---

### 3️⃣ Test the Application

1. Open **http://localhost:5173**
2. Click "Get Started" → Sign up
3. Create your first resume (7 steps)
4. Get scored out of 100%
5. Reach 65%+ to unlock duplication!
6. Download your professional PDF
